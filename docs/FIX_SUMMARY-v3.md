# SATSSDV-Go 第三轮修改记录（2026-11-04）

本轮基于上一轮 v2 修复源码继续修改。`arcss_panel_pc-change_title.zip` 作为 UI/协议设置参考；主程序协议收发、图像恢复与发射仍由 SATSSDV-Go 自身实现。

## 本轮改动

### AX.25 SSID
- 将本台 AX.25 SSID 输入移入 TX 标题栏的“发射设置”，紧邻图片质量控件左侧；仅 TX profile 选择 SSDV AX.25 时显示并启用。
- 设置范围为 0–15，沿用 `settings.json` 持久化。
- RX 不按 SSID 过滤帧；保留 AX.25 源地址 SSID 元数据，并在 RX 侧 CALL 右侧显示。
- 新增 AX.25 SSID 0、1、7、15 的实际调制/流解调元数据回归测试。

### SSDV 实时预览及丢包提示
- 每个通过 SSDV RS/CRC 校验且被接收管理器接受的新包都会产生一次 RX 更新；图像已具备可解码前缀后，每个后续有效包都会重新生成预览并覆盖更新界面。
- 图像画布保持完整目标尺寸，不随扫描进度改变大小；在已知包序号范围内对缺失包对应的估算区域叠加损坏纹理。
- 磁盘 PNG/原始包归档仍按批次/完成事件写入，避免每个 RF 包触发磁盘 IO；这不影响逐包 UI 更新。
- 由于当前 SSDV TX 熵流使用 `MCUOffset=0xff` / `MCUIndex=0xffff` 连续流 sentinel，丢包区域是基于包序号的估算标记，并非精确 MCU 定位；缺失块无法凭空恢复。实现已为损坏区域提供可见提示，但尚未实现 Hamstation 式精确 MCU 重同步。

### 相册时间与重复记录
- TX 记录时间取音频发射开始时间，而不是编码准备时间或发射结束时间。
- RX 同一接收会话的记录在完成时将时间更新为接收结束时间。
- 抽取通用会话合并逻辑，按 profile/callsign/image ID/session ID 合并“先有原始包、后有图像预览”及其他同会话重复记录，同时保留图片路径、原始包路径和较大的包计数。
- 新增纯 Go 单元测试，验证图像记录与 packet-only 记录合并，并确保不同接收会话不被合并。

### 1500 Hz 发射测试音
- TX 开始/停止按钮右侧新增 1500 Hz 测试音按钮。
- 后端通过当前 audio duplex / TX 音频与 PTT 路径异步发射 2 秒 1500 Hz 正弦信号，具有短淡入/淡出；复用现有 Stop TX 取消与忙状态保护。

### PCSI MMT 发射效率
- 将 RGB→YCbCr 转换和 Y/Cb/Cr 平面缓存前移到 encoder 初始化阶段，避免每个 packet 反复读取图像和转换颜色。
- 按图片尺寸预设映射色度压缩参数：low=80、medium=60、high=40（旧值为 20）。更高参数减少每包色度三元组、增加亮度采样数量，提高每包覆盖像素数，从而减少包数和空中时间；代价是色度细节降低。
- 640×480、12-bit 的典型测试配置下，旧参数 20 为约 800 包；参数 40/60/80 分别约为 764/752/745 包，约减少 4.5%/6.0%/6.9%。实际结果受图像尺寸和取整影响。
- 新增 packet-count 回归测试，确保三个发送预设均比旧参数减少数据包。
