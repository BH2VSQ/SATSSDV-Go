# SATSSDV-Go v5 修复说明

## 本轮修改

1. SSDV MCU 预览中未接收、丢失或无法解码的 MCU 区域统一使用淡灰色纯色填充 `#DADCDE`（RGB 218,220,222）；不再使用深色底纹或红色斜纹。整张图初始画布也使用相同淡灰色，后续成功解码的块覆盖对应位置。
2. RX/TX 频谱区域调整为主瀑布图 + 右侧星座图预留栏，主瀑布图宽度约 84%，右侧约 16%。
3. 循环发送时发送间隔输入框锁定；TX 队列在两轮发射之间每秒发送倒计时事件，UI 数字逐秒下降至 0。发射开始/完成时恢复原始设定值，下一轮重新倒计时。关闭循环发送后恢复编辑。
4. 模板变量 `{HISCALL}` 在对方呼号为空时显示 `TOCALL`。
5. RX 预览窗口固定高度范围，所有输入图像统一 `object-fit: contain` 居中显示，避免高质量图像超出窗口或因分辨率变化而撑开区域。
6. 相册 UI 继续按 `createdAt` 倒序排列；后端 `GetAlbum` 已使用 newest-first 排序。

## 测试

- `go test ./...`：通过。
- `go vet ./...`：通过。
- `node --check frontend/app.js`：通过。
- `node frontend/ui_structure.test.cjs`：通过，新增固定预览、星座预留栏、循环间隔锁定、TOCALL 检查。
- SSDV 预览测试新增缺失 MCU 中心像素必须为淡灰色的断言：通过。
- TX queue 新增两轮循环倒计时事件测试：通过。

本机安装 Go 1.23.2；测试期间仅临时把 go.mod 的 go 指令降为 1.23 以使用本地工具链，测试结束后已恢复项目原始 `go 1.26.0`。

## 尚未完成/限制

- 当前 RX/TX 音频频谱事件仅提供幅度频谱数据，没有提供解调器的复数 I/Q 符号样本。因此本轮完成了星座图显示区域布局和网格占位，但没有伪造星座点。要显示真实星座图，需从各模式的载波恢复/符号抽样环节导出 I/Q 样本并通过 Wails 事件传给前端；这需要针对 AX.25 AFSK 与 CCSDS 两类不同调制链分别接入。
- Wails 原生桌面构建未在本轮执行；真实电台全双工/循环发送 UI 需在 Windows/Linux 桌面环境进一步验收。
